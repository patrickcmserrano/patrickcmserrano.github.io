Professional Experience

Founder & Software Architect

Daelaam / Rohana

2026 - Present

Conception, architecture, and full engineering of Rohana, a multi-tenant Clojure engine for conversational AI agents tailored for SMEs, featuring isolated document RAG, declarative guardrails, and omnichannel connectivity (WhatsApp & Telegram).

Key Achievements:

  • Graph Orchestration with Pathom 3: Every agent capability (intent resolution, vector retrieval, guardrails, LLM) modeled as an independent resolver — executing only the nodes strictly required for each conversation turn.
  • Physical Multi-Tenant Isolation (LGPD by Design): Dedicated vector indexes per tenant (TurboVec in-process via libpython-clj and Qdrant) with fail-closed validation at the store layer, preventing any cross-tenant data leakage.
  • Event Messaging with Aeron IPC: Migrated internal event bus to shared-memory Aeron media driver (IPC), achieving sub-microsecond local messaging latencies.
  • Fail-Closed Privacy Gate & Strict Grounding: PII scrubbing with Presidio pt-BR before inference, and verifiable grounding requiring explicit factual citations from ingested corpora.
  • Zero-Code Declarative Onboarding: Complete tenant configuration via declarative EDN files specifying personas, business hours, and active channels (WhatsApp and Telegram).

AI Infrastructure Engineer & Software Architect

Instituto CTNI (NeoTek Partnership)

  • Observe/Plan/Act/Verify Agent Pipeline: Multi-role Clojure orchestrator for automated engineering workflows (planner → implementer → test runner → reviewer → release gate) backed by 815 tests and 3,104 assertions.
  • Security, Identity & Tamper-Evident Audit: Keycloak and OpenLDAP corporate SSO integration with strict RBAC; immutable audit trail using cryptographic SHA-256 chained hashes, integrity verification endpoints, and PII redaction.
  • Infrastructure as Code on FreeBSD: Reproducible provisioning with OpenTofu and Ansible across VNET jails, WireGuard meshes, and deny-by-default packet filter (pf) firewalling.

Founder & Quant Developer

Nexus Quant

2025 - Present

Quantitative research and systems development for the Ark algorithmic trading platform: high-frequency order book ingestion, bitemporal ledgering, and execution guided by immutable risk rules.

Key Achievements:

  • Bitemporal Ledger in Clojure & XTDB (Ark Engine): Decoupled valid time from transaction time for market events, providing point-in-time correctness for backtesting without lookahead bias.
  • Sensory Re-architecture to Go (Ark Streams): Migrated multi-exchange parallel order book ingestion (Bitget, OKX, Bybit) to Go over NATS JetStream, cutting memory usage by >70% and achieving ~66µs per 100 candles.
  • Native Desktop Operations Console (Ark Terminal): Built native operations desktop console in Go + Svelte 5 + Wails v2 with ultra-fast Go↔frontend IPC bridge (~1µs latency), streaming order books, aggression, and liquidations in real time.
  • Risk Governance as Code ('NQ-GOV-001 Constitution'): Hard stops in pure BigDecimal for drawdown, max leverage, and stale data, rigorously validated with generative tests (test.check) before any execution path.

Módulo de Inteligência

Data Auto-Pipelines on Datomic

ClojureDatomicPipelines de Dados

Project Overview

The Intelligence Module was Moleque's data layer aimed at payments intelligence. I built auto-pipelines to integrate with services such as Getnet, Pagar.me, Rede, ClearSale, MercadoPago, VTEX, and Unico, optimising the collection, processing, and storage of data in the Datomic database. The goal was to turn scattered calls to providers into a structured, queryable data flow.

Architecture & Implementation

Auto-pipelines in Clojure, one per provider, normalising each service's responses into a common data model. The destination was Datomic, chosen for its immutable nature and history — every transaction is recorded, which allows querying the state of the data at any point in time. It is the same idea of immutability and history that shows up today in my projects with XTDB and Datahike.

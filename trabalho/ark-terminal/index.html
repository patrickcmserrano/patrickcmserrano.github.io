Project Overview

The visual command center ('Control Panel') of Nexus Quant. It is a lightweight native desktop application, built with Wails, that connects to the Ark Streams backend over NATS JetStream to display market data, aggression, liquidations, backtests, and strategy signals in real time. The surface spans from candle streaming and indicator snapshots to exchange operations — orders, leverage, margin, and positions. Charts are rendered with lightweight-charts, chosen over a WebGL stack for handling market data volume at a predictable rendering cost.

Architecture & Implementation

Native desktop application via Wails v2 (Go on the backend, Svelte 5 + TypeScript/Vite on the frontend). It connects to the Ark Streams backend over NATS JetStream, using Key-Value buckets for state and streams for market data. The frontend renders with lightweight-charts. It was extracted from the ark-streams monorepo in 2026-07 via git subtree split, preserving history; before that it lived under the name "Nexus Terminal".

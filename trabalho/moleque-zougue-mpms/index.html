Project Overview

Zougue MPMS was a catalog-management product. I built the interfaces with Clojure and React, implementing catalog management and an item-deduplication mechanism — the problem of the same item showing up repeatedly across different sources.

Architecture & Implementation

Frontend in Clojure and React. The central technical piece was item deduplication: recognising when the same item arrived through different paths and consolidating it in the catalog.

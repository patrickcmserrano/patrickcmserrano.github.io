Project Overview

fexô was Moleque's real-estate project: a platform connecting people who want to buy or sell property to brokers. I joined during the planning stages and took part in developing the basic UI features, with ClojureScript, React Native, and tools like Pathom and Datomic — and then continued on the mobile application with Fulcro and React Native.

Architecture & Implementation

A web and mobile application in ClojureScript. The frontend used Fulcro and React Native, with Pathom for the data graph and Datomic as the backing database. The platform covered the property cycle: listing, negotiation, purchase, and sale.

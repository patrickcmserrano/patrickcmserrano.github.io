Pix and Credit-Card Adapters

ClojurePixIntegração de Pagamentos

Project Overview

I was responsible for developing and certifying Moleque's payment adapters: Pix and credit card, integrating with the services Adyen, Cielo, Clearsale, VTEX, Rede, among others. The work covered the adapter's full cycle — from implementing the provider's API to certification — including QR Code generation for Pix.

Architecture & Implementation

One adapter per provider, behind a common interface. Each integration (Adyen, Cielo, Clearsale, VTEX, Rede...) had its own API particularities, and the adapter was the layer that normalised them for the Payment Engine. Certification against each provider's environment was part of the job, not a separate step — it is what ensures a payment works end to end before going to production.

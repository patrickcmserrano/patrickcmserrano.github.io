Project Overview

An agent asked to work on an unfamiliar repository spends most of its budget just discovering what exists: listing directories, firing glob and grep calls, and re-reading the same files on every new session. context-graph-engine (repo-index) eliminates that waste by computing the repository's structure once, 100% deterministically, with zero LLMs, zero embeddings, and zero network calls.

The binary extracts filesystem facts, Git state (with credentials stripped), Clojure namespaces (requires, aliases, public vars, reader conditionals), Go packages (module path, imports, exported symbols), dependencies (deps.edn / go.mod), dev commands, tests, and security surfaces. Everything serializes byte-identically — no timestamps or absolute paths — with every derived fact carrying exact provenance (source, line, rule, confidence).

Architecture & Implementation

The pipeline strictly separates four layers that never mix: (1) Index (scan): what exists in the repository with exact provenance (facts.json + graph.json); (2) Navigation (navigate): what is relevant to a declarative task profile (--task), applying explicit, auditable policy without LLMs; (3) Pack (pack): what fits within the token budget (--budget-soft / --budget-hard) and in what stable order; (4) Agent (envelope): the final text handed to the agent at Turn 0.

It also provides staleness checks (verify returning OK, STALE_INDEX, INDEX_INVALID), snapshot diffing (diff), structured queries (query), and protected-artifact enforcement (protect returning WRITE_DENIED). In real comparative benchmarks, the stable-prefix envelope pushed prompt cache hit rates to 94–95%, cutting cost by 82% and wall-clock time by 97%.

Project Overview

Uma plataforma de streaming de dados que consome feeds de alta frequência de múltiplas exchanges (Order Book L2/L3 e liquidações de Bitget e Binance) e dados macro do Yahoo Finance. Executa cálculos analíticos contínuos em tempo real e emite sinais operacionais de entrada/saída. Alimenta o Nexus Terminal via WebSocket.

Architecture & Implementation

Ingestão paralela assíncrona escrita em Go. Os dados brutos alimentam filas persistentes no NATS JetStream. O FractalEngine consome essas filas e calcula os indicadores de Bill Williams (Alligator, AO, AC, MFI e fractais). A estratégia AlligatorTrend analisa o fluxo de 5 minutos gerando sinais operacionais.

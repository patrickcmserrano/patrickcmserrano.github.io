Polylith Refactoring and Distributed Processing with Onyx

ClojurePolylithOnyx

Project Overview

The Payment Engine is Moleque's payments core. I led the refactoring of the Payment Engine and the Formiguinhas Service to the Polylith architecture, promoting modularity, reuse, scalability, and testability. Next, I implemented Onyx to manage asynchronous tasks — such as report generation: I configured workflows to process commands (e.g., "generate report") as a daily scheduled task that generated and emailed the reports, ensuring scalability and responsiveness.

Architecture & Implementation

The refactoring moved the core to Polylith — isolated components and bases, with business logic separated from I/O. On that base, Onyx came in as the distributed-processing engine for asynchronous tasks: workflows consumed commands and ran them as a scheduled task, publishing the result (the report) back by email. It is the same distributed-systems vocabulary that shows up today in my own products.

Project Overview

A personal project designed to track price fluctuations across multiple partner platforms. The architecture adopts the Pure Core / Impure Shell model, isolating complex business logic, rate-limiting rules, and dynamic scrapers from side effects. The Datahike graph database is used to model and query complex relationships between products.

Architecture & Implementation

Graph-based architecture (Pathom 3) integrated with an immutable database (Datahike) featuring time-travel capabilities. Ingestion runs via scrapers (HTTP/Etaoin) orchestrated by GitHub Actions and VPS servers, producing encrypted reports (Vault Mode) and sending alerts via Telegram.

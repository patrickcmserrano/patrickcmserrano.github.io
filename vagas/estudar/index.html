O rótulo não é o requisito

O painel da /vagas conta vagas por rótulo. O que decide o estudo é o que o anúncio escreve dentro do rótulo — e aí os números mudam de forma. Azure é o mais pedido (24 vagas), mas só 16 exigem Azure de verdade: o resto cita Azure como certificação, preferência ou uma alternativa a menos de três palavras (8 anúncios). Na ordem inversa, o Bedrock — variante AWS nomeada dentro do rótulo AWS — não aparece em rótulo nenhum do painel.

O que não entra na trilha

Lacunas fora dos grupos acima. Onde o anúncio escreve "ou", a alternativa já é cobertura — estudar seria perseguir uma linha em vez de uma vaga.

Cada contagem desta página é derivada do mesmo src/data/vagas-ia.json que alimenta a /vagas, em tempo de build — nunca escrita à mão. "Pede de verdade" é um critério textual: o trecho do anúncio deixa de ser requisito quando é só certificação, diferencial ou uma alternativa com "ou". Contagens são por vaga, não por aparição de termo.

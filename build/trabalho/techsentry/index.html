Project Overview

Sistema projetado para monitorar flutuações de preços em múltiplas plataformas parceiras. A arquitetura adota o modelo Pure Core / Impure Shell, isolando a lógica de negócio complexa de rate-limiting e scrapers dinâmicos de efeitos colaterais. O banco de dados orientado a grafos Datahike é usado para manter relações complexas de produtos.

Architecture & Implementation

Event Sourcing distribuído construído sobre NATS JetStream para enfileiramento resiliente. Nós coletores consomem filas de scraping respeitando políticas rígidas de backoff exponencial e rate-limiting por host. Os dados brutos passam por normalização usando Pathom 3 e persistem no Datahike.

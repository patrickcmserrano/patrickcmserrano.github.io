Project Overview

Running a coding agent on an isolated bug is easy; the engineering challenge begins when chaining 15 consecutive tasks across production repositories without hallucinated signatures, broken master branches, or exhausted quota windows. swe-dispatcher solves this with two complementary engines in Clojure/Babashka: sprint_runner.clj (chained serial sprint orchestration with claude -p or agy -p over stream-json) and swe_runner.clj (headless execution via small-router with automated PR delivery via ark-swe[bot]).

Each task runs confined to its own Git worktree (feat/<ID>), inheriting the previous task's branch via chain-plan without touching master. It also provides end-to-end OTLP telemetry (agy-otlp-hook) correlating task.id and session_id with actual costs in small-router.

Architecture & Implementation

Operations rely on three deterministic pillars: (1) Turn-0 CGE Context: upon creating each worktree, the dispatcher automatically runs repo-index scan, verify, and pack --format envelope so the agent receives fresh, exact signatures from the previous task. (2) Fail-Closed Gates (Red → Green): in sprint-runner, the Test-First Gate enforces a tests-only first commit (Red) before implementation commits pass :gate-cmds; in swe-runner, existing tests are locked physically with chmod 0444 (Locked-Test) so agents cannot relax assertions to pass. (3) Heterogeneous Quota Bin-Packing (sprint_windows.clj & sprint_autoresume.clj): models independent quota buckets (5h Anthropic window, Gemini shared quota, Argon, DeepInfra), routing tasks by technical risk and auto-resuming seamlessly across renewal windows.
